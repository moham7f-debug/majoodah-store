# قالب متجر مجودة لسلة (Twilight)

قالب سلة عربي RTL للمنتجات التعليمية (سجلات وملفات إنجاز ولوحات مدرسية)، مبنيّ من
تصميم «متجر مجودة» الثابت وتحويله إلى قالب **Twilight** رسمي قابل للنشر على سلة.

> **البيانات تجريبية:** منتجات الصفحة الرئيسية (سجلات، ملفات إنجاز…) وهمية — كما في
> التصميم الأصلي — لغرض العرض. لعرض منتجات متجرك الحقيقية، راجع قسم
> [الربط بمنتجات سلة](#الربط-بمنتجات-سلة-الحقيقية).

## هيكل الملفات

```
(جذر المستودع)
├── twilight.json                  # بيانات القالب + إعدادات التخصيص (ألوان/واتساب/بانر)
├── package.json                   # سكربتات Salla CLI
└── src/
    ├── assets/
    │   ├── styles/app.scss         # كل تنسيقات التصميم (Design tokens + RTL responsive)
    │   └── js/app.js               # السلة التجريبية، البحث، العدّادات، القائمة، زر الأعلى
    ├── views/
    │   ├── layouts/master.twig     # الهيكل العام (يُحقن فيه salla.header / salla.footer)
    │   ├── pages/index.twig        # الصفحة الرئيسية بكل الأقسام + بيانات المنتجات التجريبية
    │   └── components/
    │       ├── announcement.twig   # الشريط الإعلاني العلوي
    │       ├── header.twig         # الهيدر (شعار/بحث/أيقونات/تصنيفات)
    │       ├── footer.twig         # الفوتر
    │       ├── product-card.twig   # بطاقة منتج (تجريبية)
    │       └── cart-drawer.twig    # درج السلة الجانبي
    └── locales/
        ├── ar.json                 # النصوص العربية
        └── en.json                 # النصوص الإنجليزية
```

```bash

```

## التشغيل محليًا (معاينة)

من **جذر المستودع** (حيث يوجد `twilight.json`):

```bash
# 1) تسجيل الدخول لحساب الشريك
salla login

# 2) بناء ونشر ومعاينة القالب محليًا (مع إعادة البناء التلقائي عند التعديل)
salla theme preview
```

> أمر `preview` هو الذي يبني القالب ويعاينه — لا يوجد أمرا `watch` أو `build`
> منفصلان في Salla CLI. يطبّق التغييرات على ملفات `.twig` و `app.scss` و `app.js` مباشرة.

## النشر على متجرك

```bash
# رفع القالب لسلة وتقديمه للمراجعة/النشر — بدون أي وسائط
salla theme publish
```

> ⚠️ **مهم — أكثر خطأ شائع:** أمر `salla theme publish` لا يقبل أي وسائط (arguments)
> على الإطلاق. **لا تكتب اسم القالب ولا وصفه ولا أي مسار بعده.** القالب الذي سيُنشر
> يُحدَّد من **المجلد الذي أنت واقف فيه** (يجب أن تكون في جذر المستودع حيث `twilight.json`).
>
> - ❌ خطأ: `salla theme publish قالب متجر مجودة` ← 3 كلمات = `Expected 0 arguments but got 3`
> - ❌ خطأ: `salla theme publish mojawada-theme` ← كلمة زائدة = `got 1`
> - ✅ صحيح: `salla theme publish` ← لا شيء بعده
>
> كل كلمة عربية تُحسب وسيطًا منفصلًا، لذلك تظهر أرقام مثل got 3 أو got 8 بحسب عدد
> الكلمات المكتوبة. ولا تستخدم `npm publish` (أمر npm مختلف تمامًا).

بعد قبول النشر، فعّل القالب من:
**لوحة تحكم سلة ← المتجر ← تصميم المتجر ← اختيار القالب**.

### أوامر Salla CLI للقوالب (للمرجع)

| الأمر | الوظيفة |
|---|---|
| `salla theme create` | إنشاء قالب جديد |
| `salla theme preview` | بناء + نشر + معاينة محلية |
| `salla theme list` | عرض قوالبك |
| `salla theme publish` | تقديم القالب للنشر (بدون وسائط) |
| `salla theme delete` | حذف قالب |

## التخصيص من لوحة تحكم سلة

عرّفنا إعدادات القالب في `twilight.json`، فتظهر في محرّر القالب داخل سلة وتُطبَّق فورًا:

| الإعداد | الوصف | الافتراضي |
|---|---|---|
| اللون الأساسي | لون الهوية الأخضر | `#0e7c6b` |
| اللون المميز | الذهبي للتأكيدات | `#f3b14a` |
| لون العناوين | لون النصوص الغامقة | `#16302b` |
| الشريط الإعلاني | إظهار/إخفاء + النص | مفعّل |
| رقم واتساب | للأزرار وإتمام الطلب | `966500000000` |
| البانر الرئيسي | الشارة/العنوان/الوصف | نصوص التصميم |

الألوان تُحقن في `master.twig` كمتغيّرات CSS (`--green`, `--gold`, `--ink`)، فأي تعديل
من اللوحة ينعكس على كامل القالب دون لمس الكود.

### التعديل اليدوي
- **الألوان:** متغيّرات `:root` أعلى `src/assets/styles/app.scss`.
- **المنتجات التجريبية:** مصفوفة `products` أعلى `src/views/pages/index.twig`
  (الحقول: `title`, `price`, `was`, `cat`, `badge`, `color`, `group` = `best` أو `new`).
- **رقم واتساب:** يُفضّل تغييره من إعدادات القالب، أو ابحث عن `966500000000` في الملفات.

## الربط بمنتجات سلة الحقيقية

القالب حاليًا يعرض **بيانات تجريبية**. لعرض منتجاتك الفعلية من سلة، استبدل الحلقة
التجريبية في `src/views/pages/index.twig` بمكوّن سلة الرسمي `salla-product-card`
مع بيانات المتجر الحقيقية، مثال:

```twig
{# بدل الحلقة التجريبية: #}
<div class="products">
  {% for product in products %}
    <salla-product-card
      shadow-on-hover
      :source="{{ product | json_encode }}">
    </salla-product-card>
  {% endfor %}
</div>
```

حيث `products` متغيّر تُمرّره سلة تلقائيًا لصفحة الرئيسية (أو استخدم
`{% hook 'home.products' %}` / مكوّنات القالب في `twilight.json` لعرض منتجات
مختارة). عند الانتقال للمنتجات الحقيقية، استخدم **سلة سلة الرسمية** (`salla.cart.addItem`)
بدل السلة التجريبية في `app.js`، ومكوّن `<salla-cart-summary>` لدرج السلة.

راجع توثيق سلة الرسمي:
- منصة Twilight: <https://docs.salla.dev/>
- مكوّنات الواجهة (Web Components): <https://docs.salla.dev/419565m0>

## ملاحظات

- `{{ salla.header }}` و `{{ salla.footer }}` في `master.twig` تحقنان أصول سلة
  الأساسية ومكتبة مكوّناتها وملفات القالب المُجمّعة — لا تحذفهما.
- التصميم متجاوب بالكامل (حتى 360px) ويدعم RTL والوصولية (skip link، `aria-*`،
